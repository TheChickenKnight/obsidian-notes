
# Set
A collection of non-repeated items that have at least one property in common.
## Set Notation
$\text{Name}=\{ \text{elements}\}$
Sets are contained with braces.
### Name
A name is given to a set to reference it, usually an upper case letter
### Elements
The actual items in the set, if letters, are normally lowercase.

## Set Representation
### Listing Method
Writing down every item in the set $$A=\{2,4,6,8\}$$
### Set Description
Using words to describe the similarities of the Elements in the set
$$A=\text{the set of all positive even numbers}$$
### Set Builder Notation
We use Math notation or Math language to write/describe a Set.
$$A=\{x|x=2k, 1\le k<\infty\}$$
*Must use math notation completely, unless there is literally no way to describe the set otherwise.*

# Sets of Numbers
## Natural Numbers
$$\mathbb{N}=\{1,2,3,4,...\}$$
## Whole Numbers
$$\{0,1,2,3,4,...\}$$
## Integers
$$\mathbb{Z}=\{...,-4,-3,-2,-1,0,1,2,3,4,...\}$$

## Rational Numbers
$$\mathbb{Q}=\{\frac{p}{q}|p\text{ and }q\text{ are integers, and }q\ne0\}$$
## Irrational Numbers $\mathbb{R}$
Any element which is not in the set of Rational Numbers
## Real Numbers 
Any element that can be expressed as a decimal
## Complex Numbers
Real Numbers and Imaginary numbers in every combination.

# Subsets
A set $B$ is called a **subset** of $A$, iff $\forall x \in B \Rightarrow x \in A$ 
$$B\subseteq A$$
